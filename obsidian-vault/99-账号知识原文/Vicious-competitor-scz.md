# 他的十大致命弱点 · 竞争者视角排序

> 排序标准只有一条：**我抓住这个弱点之后，他的反击难度有多大。**

> 数据基础：2026-09-06 全量审计（16 仓 / 50 分支 / ≈1,543 提交 / 36 收藏 / 2 个在线站点实测）。

## ⚔️ No.1 手写代码证据为零 ——「让他离开 Agent，他就离开战场」

**铁证**：16 个生产仓，67%–100% 提交由 Arena agent 共同署名；他本人邮箱（`2253710052@stu.xjtu.edu.cn`）署名的提交清单全页翻完是：`Create 期末A.zip`、`Create U01网页.zip`、`Add files via upload`、`Create rotor37_pc.npz`、merge 操作、`御风记14`。**没有一行能证明是他手写的逻辑代码。** 全账号无 C/C++/Fortran/CUDA 痕迹，无算法竞赛，无 LeetCode。更妙的是：2026-09-06 上午 09:32，他 star 了 `jerry-git/learn-python3`——大一结束了，还在收藏 Python 入门教程，这是他自己給自己按的手印。

**我的打法**：把考核拖进任何形式的**现场编程/白板手写**。课题组考核、推免面试、上机测试——只要环境里没有 Agent，他的全部工程光环（398 commits 的旗舰平台）瞬间变成"无法验证的自述"。我只需要在现场写出一个能跑的 Kriging 相关矩阵乘法，就是 1:0。

**他的修复窗口**：一个 100% 手写、带手写测试的小项目即可部分止血——但他今天收藏 learn-python3 说明他自己知道地基没打好，补齐至少要 3–6 个月。

## ⚔️ No.2 没有一滴他自己算的 CFD ——「数据是你算的吗？」

**铁证**：旗舰平台的全部数据是**公开 PLAID/NASA Rotor 37 数据集**；SU2 求解器验证停在 **E3 粗网格一阶 1000 步**，355 万细网格二阶收敛他自己写着"留待 HPC"（线上站方法论页原文）。也就是说：**上千组 CFD 样本，没有一组出自他手；网格没有一张是他画的。** 而郭老师是什么人？做跨声速风洞**实验**、做真实 RANS 闭环的人——20 篇论文里最硬的那几篇全是"真物理兑现"层。

**我的打法**：面谈时只需要替郭老师问出那一问："**这些 CFD 是你自己算的吗？网格独立性你做过吗？**"他的诚实纪律（E0–E4 分级）反而逼他必须亲口回答"不是"。他最大的优点——不吹牛——在这一问里会变成扣分项，因为他连"吹"的资格都没挣到。我只要拿出**一个自己画网格、自己跑到二阶收敛的案例**，就在"物理可信度"这条轴上形成他有我无。

**他的修复窗口**：需要算力 + 网格生成学习 + 收敛调试，以他每周 4–6 小时（见 No.4），一个完整 E4 案例至少吃到明年。

**他的修复窗口**：他比任何人都清楚 T1–T8 值多少钱，但他每周 4–6 小时（No.4）+ 零手写能力（No.1）+ 无算力（No.2）三座大山压着，执行速度就是快不起来。**他最大的风险不是没想到，而是想到了却做不完。**

**他的修复窗口**：砍项目。但砍哪个都疼——每个仓都是他"给具体的人做具体的东西"人格的延伸。他的温情会成为他的包袱。

### `tools/make_grids.py`（全文；属工具类，可复制）

```python
"""S10′: 三档网格生成。用法: python tools/make_grids.py"""
from pathlib import Path
import gmsh

LEVELS = {"L1": 0.012, "L2": 0.006, "L3": 0.003}   # 细化比 r=2（≥1.3 达标）
ROOT = Path(__file__).resolve().parents[1]
tpl = (ROOT / "mesh" / "naca0012.geo").read_text(encoding="utf-8")

for name, lc in LEVELS.items():
    tmp = ROOT / "mesh" / f"_{name}.geo"
    tmp.write_text(tpl.replace("LC_TOKEN", repr(lc)), encoding="utf-8")
    gmsh.initialize()
    gmsh.option.setNumber("General.Terminal", 1)
    gmsh.open(str(tmp))
    gmsh.model.mesh.generate(2)
    out = ROOT / "mesh" / f"mesh_{name}.su2"
    gmsh.write(str(out))
    tags = gmsh.model.getPhysicalGroups(1)
    marks = [gmsh.model.getPhysicalName(d, t) for d, t in tags]
    # 勘误#6 (09-09)：gmsh 4.x Python API 的 getElements(2) 结构不可靠（len(e[0]) 直接崩）；
    # 改读 .su2 的 NELEM= 行——SU2 实际读到的量（.su2 头没有 "# 2D ELEMENTS" 注释行，数那个也崩）
    txt = out.read_text(encoding="utf-8").splitlines()
    n2 = sum(int(l.split()[1]) for l in txt if l.startswith("NELEM="))
    print(f"[{name}] lc={lc} 单元数={n2} markers={marks} -> {out.name}")
    gmsh.finalize()
    tmp.unlink()
```

## S13′ · 🔒 收敛史解析器（2h，手敲）

`src/convergence.py`（规格：输入 history.csv → 输出摘要 dict；平台期定义=迭代末 25% 段）：

```python
"""S13′ 收敛史解析器。手写模块：SU2 history.csv -> 收敛摘要。"""
from __future__ import annotations
import numpy as np
import pandas as pd


def load_history(path):
    df = pd.read_csv(path)
    df.columns = [c.strip().strip('"') for c in df.columns]

    def pick(*cands):
        for c in cands:
            for col in df.columns:
                if col.strip('"').lower() == c.lower():
                    return col
        raise KeyError(f"缺列 {cands}；实际列：{list(df.columns)}")

    return (df,
            pick("Inner_Iter", "ITER", "Outer_Iter"),
            pick("rms[Rho]"),
            pick("CD"),
            pick("CL"))


def orders_dropped(rms):
    """残差降幅（个量级）。勘误#10 (09-10 对 SU2 真跑 history.csv 实跑核验)：
    真 SU2 v8.5 history.csv 的 rms 列**已是 log10 值**（如 -2.759，可为负），
    再取 log10 得 NaN；旧演示 fixture 是线性值（全正）所以测试全绿。
    判别：出现负值必为 log10 列（线性 RMS 恒正）→ 直接差值；否则按线性取 log。"""
    x = np.asarray(rms, float)
    x = x[np.isfinite(x)]
    if x.size == 0:
        return float("nan")
    if (x < 0).any():
        return float(x[0] - x.min())
    return float(np.log10(x[0]) - np.log10(x.min()))


def plateau_stats(values, tail_frac=0.25, min_tail=50):
    x = np.asarray(values, float)
    x = x[np.isfinite(x)]
    k = max(min_tail, int(len(x) * tail_frac))
    t = x[-k:]
    mean = float(t.mean())
    std = float(t.std(ddof=1))
    return dict(n=k, mean=mean, std=std,
                rel_std=std / abs(mean) if mean else float("inf"),
                samples=t.tolist())


def summary(path):
    df, it, rms, cd, cl = load_history(path)
    return dict(file=str(path),
                iters=int(df[it].iloc[-1]),
                orders_drop=orders_dropped(df[rms]),
                CD_mean=plateau_stats(df[cd])["mean"],
                CL_mean=plateau_stats(df[cl])["mean"],
                CD_plateau=plateau_stats(df[cd]))
```

## S14′ · 🔒 GCI 模块（2h，手敲）

`src/gci.py` 规格：等比三档（本项目 r=2）→ 观察阶数 p、Richardson 外推值、GCI%。公式源：Roache / Celik et al. (2008) 标准。

```python
"""S14′ 网格收敛指数（等比三档，Roache/Celik 2008 标准）。手写模块。"""
from dataclasses import dataclass


@dataclass
class GCIResult:
    p_obs: float          # 观察阶数（与理论阶对照：一阶≈1，二阶≈2）
    phi_ex: float         # Richardson 外推"连续解"
    gci_fine_pct: float   # 细网格上的不确定度（Fs=1.25，95% 置信）
    gci_med_pct: float
    e21: float
    e32: float


def gci(phi_fine, phi_med, phi_coarse, r=2.0, Fs=1.25):
    if abs(r) <= 1.0:
        raise ValueError("细化比 r 必须 > 1")
    e21 = phi_med - phi_fine
    e32 = phi_coarse - phi_med
    if e21 == 0 or e32 == 0 or ((e21 > 0) != (e32 > 0)):
        raise ValueError(
            f"不在单调渐近收敛区：e21={e21:g}, e32={e32:g}；"
            "对策=再加细一档，或检查三档是否同一收敛口径")
    p = __import__("math").log(abs(e32 / e21)) / __import__("math").log(r)
    phi_ex = phi_fine + (phi_fine - phi_med) / (r ** p - 1)
    g21 = Fs * abs(e21 / phi_fine) / (r ** p - 1) * 100 if phi_fine else float("inf")
    g32 = Fs * abs(e32 / phi_med) / (r ** p - 1) * 100 if phi_med else float("inf")
    return GCIResult(p, phi_ex, g21, g32, e21, e32)
```
（手敲时把 `__import__("math")` 换成顶部正常 `import math`——这里是为了行内自包含。）

## S15′ · 🔒 Δ_min 显著性模块（2.5h，★全计划心脏）

`src/significance.py` 规格：Δ_min = max(GCI 绝对量, 平台期 bootstrap 95%CI 半宽)；判据函数 `is_significant`。

```python
"""S15′ 最小可分辨增量框架（bootstrap 口径）。手写模块。
宣称增益 > Δ_min 才可称"成果"——白皮书 6.2① 的可执行化。"""
import numpy as np
from src.gci import gci


def bootstrap_ci(samples, B=10000, alpha=0.05, seed=42):
    """平台期样本 -> (CI下界, CI上界, 半宽)。均值统计量。"""
    rng = np.random.default_rng(seed)
    x = np.asarray(samples, float)
    n = x.size
    boots = np.empty(B)
    for b in range(B):
        boots[b] = rng.choice(x, n, replace=True).mean()
    lo, hi = np.quantile(boots, [alpha / 2, 1 - alpha / 2])
    return float(lo), float(hi), float((hi - lo) / 2)


def delta_min(plateau_samples_fine, phi_fine, phi_med, phi_coarse,
              r=2.0, B=10000):
    """合成最小可分辨增量：网格不确定度与统计不确定度取大者。"""
    _, _, half = bootstrap_ci(plateau_samples_fine, B=B)
    g = gci(phi_fine, phi_med, phi_coarse, r=r)
    gci_abs = g.gci_fine_pct / 100.0 * abs(phi_fine)
    return dict(boot_half=half,
                gci_abs=gci_abs,
                dmin=max(half, gci_abs),
                p_obs=g.p_obs,
                phi_ex=g.phi_ex)


def is_significant(claimed_delta, dmin):
    """返回 (是否显著, 边际)。claimed_delta 用绝对值口径传入。"""
    margin = abs(claimed_delta) - dmin
    return margin > 0, dict(margin=margin,
                            verdict="显著" if margin > 0 else "不可分辨")
```
