# 项目地图：SCZ_Archived

这个仓库是多个一次性单页项目的归档快照，不是一个单一产品。它最有价值的部分是可复用的内容和交互模式。

## 内容资产

- `ai/`：AI 核心概念闪卡，38 张卡片，包含定义、例子、关键词和记忆口诀。
- `IELTS20260423scz/`：雅思学习单页，可作为英语学习内容的参考。
- `physics-exam-1/`、`physics-exam-2/`：物理练习与评估组件。
- `gaoshu-6.1/`：高数内容页。
- `wendang11/`：恋爱大师技能库材料。

## 可复用经验

- 复杂内容先拆成数据，再让 UI 呈现；不要把所有知识硬编码在组件里。
- 本地状态适合记录学习进度；真正的跨设备知识应落到 Markdown 或数据库。
- 归档项目先看 `README.ARCHIVE.md` 和 `TIMESTAMP.md`，不要假设目录仍是可运行的最新应用。
