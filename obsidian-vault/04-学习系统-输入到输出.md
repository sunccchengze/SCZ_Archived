# 学习系统：从输入到输出

## 四层回路

1. **理解**：用自己的话解释概念，不看原文也能说清。
2. **辨别**：找边界、反例和常见误区。
3. **提取**：隔一段时间回忆，而不是重复阅读。
4. **迁移**：在新问题、项目或真实任务中使用。

只有第 4 步发生，知识才真正变成能力。

## 一张知识卡片的模板

```markdown
# {{概念}}

## 一句话结论

## 它解决什么问题

## 最小例子

## 不适用 / 常见误区

## 我自己的理解

## 下一次使用场景

## 相关
- [[...]]
```

## 针对不同科目

- **英语**：例句 + 语境 + 主动造句；不要只背中文释义。
- **物理**：现象 → 模型 → 公式 → 单位/边界 → 实验或数量级检查。
- **高数**：定义 → 几何直觉 → 典型题 → 变式 → 错题原因。
- **AI**：概念 → 输入/输出 → 训练方式 → 能力边界 → 一个可运行的小实验。

## 防止“看起来学会了”

学习结束时合上资料，回答：

- 我能用一句话讲给别人听吗？
- 我能写出一个反例吗？
- 我能在新题里判断何时使用吗？
- 我能指出自己最不确定的地方吗？
