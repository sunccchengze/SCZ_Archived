# 第二大脑工作流：捕获 → 理解 → 连接 → 行动

## 1. 捕获：只记最小可用单元

看到一个想法、问题或资料时，先记下三件事：

- **触发**：我在哪里看到的？
- **原话**：重要的原句或链接是什么？
- **疑问**：它可能解决我哪个问题？

不要在捕获阶段润色长文。没有上下文的摘抄，价值通常很低。

## 2. 理解：让 DeepSeek 当教练，不当代写者

把原始材料交给模型时，使用这个提示：

```text
你是我的知识整理教练。请基于下面材料：
1. 用不超过 100 字说清核心结论；
2. 列出 3 个关键概念，并解释它们之间的关系；
3. 指出材料中可能不准确、缺证据或容易误解的地方；
4. 给出一个适合我马上实践的小实验。
不要补编材料中没有的事实；不确定时明确标注“不确定”。

材料：
{{粘贴材料}}
```

## 3. 连接：每条笔记至少链接两条旧笔记

连接不是堆标签。问三个问题：

- 它和我以前知道的什么相似？
- 它在哪些情况下不适用？
- 它会改变哪个决定或行动？

## 4. 行动：把知识变成可观察结果

把“我要学会 RAG”改成：

> 今天用 10 条自己的 Markdown 笔记做一次检索测试，记录 3 个模型答错的例子，并调整切分策略。

## 5. 每周维护

- 清理 `[[99-Inbox]]` 中超过 7 天的条目
- 给重复笔记合并，而不是继续新建
- 把一条高价值笔记改写成自己的话
- 检查模型回答是否有引用和时间范围

> 第二大脑的目标不是收藏更多，而是让下一次思考更快、更准确。
