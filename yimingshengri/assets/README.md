# Assets 文件夹

请将以下文件放入此文件夹：

1. **avatar.jpg** - 老哥的头像图片（用于任务简报页面）
   - 建议尺寸：200x200px 或更大
   - 格式：JPG 或 PNG

2. **blessing.jpg** - 祝福图片（吹灭蜡烛后显示）
   - 建议尺寸：16:9 比例，宽度至少 800px
   - 格式：JPG

3. **favicon.ico** - 网站图标
   - 建议尺寸：32x32px 或 16x16px
   - 格式：ICO 或 PNG

## 注意事项

- 图片文件名必须与代码中引用的完全一致
- 确保图片文件大小合适，以便快速加载
- 建议使用压缩工具优化图片大小
